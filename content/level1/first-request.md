# 첫 요청 해보기

> 말로 시키면 됩니다. 명령어를 외울 필요가 없습니다.

앞 단계에서 `claude`를 실행한 **그 화면**에서 이어서 합니다. 점심 메뉴를 골라 주는 웹페이지를 만들어 봅시다.

## 1. 요청하기
프롬프트 칸에 아래 내용을 **복사해서 붙여넣고 Enter**를 누르세요.

```text
점심 메뉴를 무작위로 골라 주는 웹페이지를 만들어 줘.
index.html 파일 하나로 만들고, 메뉴는 김치찌개, 돈까스, 비빔밥, 쌀국수, 짜장면, 샐러드, 햄버거, 초밥 8개를 넣어 줘.
'돌리기' 버튼을 누르면 메뉴가 빠르게 바뀌다가 하나에서 멈추게 해 줘.
디자인은 깔끔하고 귀엽게 해 줘.
```

> 잘 만들어지는 요청에는 **무엇을(점심 메뉴 뽑기), 어떤 모양으로(파일 하나), 어떻게 동작하게(버튼 → 멈춤)**가 들어 있습니다.

## 2. 권한 승인
Claude가 파일을 만들거나 명령을 실행하기 전에 **허용 여부를 묻습니다.**
- 내용을 읽고 맞으면 **Yes**
- 이상하면 No 또는 질문으로 이유를 물어보기

## 3. 결과 열어 보기
작업이 끝나면 `test-project` 폴더에 `index.html`이 생깁니다. 탐색기에서 이 파일을 **더블클릭**하면 브라우저에서 열립니다.

## 4. 고쳐 달라고 하기
마음에 안 드는 부분은 말로 다시 시키면 됩니다. 같은 세션에서 이어서 입력해 보세요.

```text
메뉴를 내가 직접 추가하고 뺄 수 있게 입력칸을 만들어 줘
```

파일을 다시 열거나 새로고침하면 바뀐 모습을 볼 수 있습니다.

## 확인 체크
- [ ] 요청한 `index.html`이 만들어졌다
- [ ] 권한 요청이 나오면 **읽고 나서** 승인할 수 있다
- [ ] 한 번 더 고쳐 달라고 요청해 봤다
- [ ] `/exit`로 종료해 봤다

## 자주 하는 실수
- 권한 요청을 **읽지 않고 계속 승인** → 중요한 폴더에서는 특히 위험합니다
- 한 대화에 주제를 섞기 → 주제가 바뀌면 `/clear`
