# Claude Code란?

> 터미널에서 실행하는 **AI 코딩 에이전트**. 답만 하지 않고 **직접 일을 끝냅니다.**

<details>
<summary>Claude와 Claude Code, 차이점을 아시나요?</summary>

![Claude(웹·앱 채팅)와 Claude Code 비교](assets/img/claude-vs-claude-code.svg)

| | Claude (웹·앱 채팅) | Claude Code |
|---|---|---|
| **하는 일** | 대화로 질문에 답하고 글을 써 줍니다 | 파일을 고치고, 명령을 실행하고, 확인까지 합니다 |
| **결과물** | 대화창의 글. 옮기는 건 내가 합니다 | 내 폴더의 파일에 바로 반영됩니다 (기본은 변경 전에 확인) |
| **파일** | 필요할 때 내가 올립니다 | 작업 폴더의 파일을 필요한 만큼 스스로 읽습니다 |
| **쓰는 곳** | 브라우저, 앱 | 터미널, IDE, 데스크톱 앱의 **Code 탭**, 웹 |
| **필요한 것** | Claude 계정 | 유료 구독(Pro, Max, Ultra, Team, Enterprise) 또는 Console 계정 |

- **같은 계정으로 로그인합니다.** Claude 구독으로 Claude Code에 로그인할 수 있습니다.
- **Claude 데스크톱 앱에는 Code 탭이 있습니다.** 채팅과 Claude Code를 한 앱에서 오갈 수 있습니다.
- **언제 뭘 쓸까요?** 메일 문장 다듬기, 궁금한 것 묻기는 Claude 채팅이 간편합니다. "이 폴더의 회의록 50개를 표 하나로 정리"처럼 내 파일을 직접 다루는 일은 Claude Code가 맡습니다.

## AI 코딩 에이전트란?

Claude Code처럼 **파일을 직접 읽고, 고치고, 실행하는 AI**를 에이전트라고 부릅니다. 대화로 답만 주는 AI와 무엇이 다른지, 같은 부탁으로 비교해 볼까요?
