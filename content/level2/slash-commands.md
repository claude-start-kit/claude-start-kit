# 주요 슬래시 명령 모음

> `/`로 시작하는 명령은 Claude Code를 **조종하는 리모컨**입니다. 목적별로만 기억하세요.

![슬래시 명령 치트시트](assets/img/slash-cheatsheet.svg)

## 매일 쓰는 5개
| 명령 | 언제 |
|---|---|
| `/clear` | 새 주제를 시작할 때 |
| `/compact` | 같은 주제를 이어가며 공간이 부족할 때 |
| `/resume` | 어제 하던 대화를 이어갈 때 |
| `/model` | 모델을 바꿀 때 |
| `/rewind` | 방금 한 수정을 취소할 때 |

## 상태를 확인하는 명령
| 명령 | 보여 주는 것 |
|---|---|
| `/status` | 버전, 모델, 계정, 설정 파일 |
| `/usage` (`/cost`) | 비용·한도·통계 |
| `/context` | 컨텍스트 사용량 |
| `/doctor` | 설치·설정 진단 (`claude doctor`는 터미널에서) |
| `/help` | 명령 목록 |

## 알아 두면 편한 명령
| 명령 | 설명 |
|---|---|
| `/btw 질문` | 대화 기록에 남기지 않는 **곁가지 질문** |
| `/ide` | 편집기(VS Code 등)와 연결 |
| `/tasks` | 백그라운드 작업 관리 |
| `/insights` | 최근 세션 분석 보고서 |

## 명령을 찾는 법
- 입력창에 **`/`만 입력** → 목록이 나타나고 글자를 치면 걸러집니다
- 전체 명령은 [Commands 레퍼런스](#/ref/slash-all)에서 검색할 수 있습니다
- 내 버전에 있는 명령은 `/help`로 확인

## 확인 체크
- [ ] `/`만 입력해 목록을 봤다
- [ ] `/status` · `/usage` · `/context`를 모두 실행해 봤다

## 자주 하는 실수
- 문서의 명령이 **내 화면에 없음** → 버전이 다를 수 있습니다. `claude update` 후 다시 확인
