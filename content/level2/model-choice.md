# 모델 고르기

> Claude에는 **크기가 다른 모델**이 있습니다. 연습하는 동안은 **가볍고 빠른 Haiku**로 시작하는 것을 권장합니다.

## 모델 3가지, 한눈에
| 모델 | 한 줄 설명 | 이럴 때 |
|---|---|---|
| **Haiku** | 가장 가볍고 빠릅니다 | 연습, 간단한 질문, 파일 정리, 반복 작업 |
| **Sonnet** | 속도와 성능의 균형형입니다 | 평소 업무, 문서·코드 작성의 기본 선택 |
| **Opus** | 가장 깊게 생각하는 고성능입니다 | 복잡한 설계, 어려운 문제 분석 |

- 큰 모델일수록 **더 깊이 생각하지만 느리고, 사용량(한도)을 더 많이 씁니다.**
- 모델 목록은 계정과 시점에 따라 조금 다를 수 있습니다. `/model`을 열면 **내 계정에서 고를 수 있는 모델**이 보입니다.

## 학습자에게 Haiku를 권하는 이유
- **빠릅니다.** 연습할 때 답을 기다리는 시간이 짧습니다.
- **한도를 아낍니다.** 구독 사용량이 천천히 줄어, 여러 번 따라 해 볼 수 있습니다.
- **이 키트의 실습은 가벼운 작업입니다.** 폴더 확인, 파일 만들기, 짧은 문서 정리는 Haiku로 충분합니다.
- 결과가 아쉬우면 **그때 Sonnet으로 올리면** 됩니다. 잃을 것이 없습니다.

## 바꾸는 방법
Claude Code 안에서 입력합니다.

```text
/model              # 선택기 열기 (화살표로 고르고 Enter)
/model haiku        # 바로 Haiku로 전환
```

처음부터 지정해 실행할 수도 있습니다.

```powershell
claude --model haiku
```

지금 쓰는 모델은 `/model`을 열면 표시됩니다.

## 이렇게 정하세요
1. **연습 중** → Haiku
2. **실제 업무** → Sonnet
3. **Sonnet으로도 막히는 어려운 작업** → Opus

> 비용·한도 확인, `opusplan`, 노력도(effort)는 [모델 선택과 비용 확인](#/level2/model-cost)에서 이어서 배웁니다.

## 확인 체크
- [ ] `/model`을 열어 고를 수 있는 모델을 봤다
- [ ] Haiku로 바꾸고 간단한 요청을 해 봤다

## 자주 하는 실수
- 연습부터 **가장 큰 모델**을 쓰기 → 한도가 빨리 줄어듭니다
- Haiku 답이 아쉬운데 **계속 같은 요청 반복** → `/model sonnet`으로 올려 다시 시도하세요
- 모델을 바꿨는데 **어떤 모델인지 확인 안 함** → `/model`로 현재 상태를 확인하세요
