# 서브에이전트

> 어려운 조사는 **전담 보조에게 맡기고 요약만 받습니다.** 메인 대화가 깨끗하게 유지됩니다.

![서브에이전트와 컨텍스트](assets/img/subagent-context.svg)

## 언제 쓰나 (공식 설명 기준)
- 검색 결과·로그·큰 파일이 **메인 대화를 가득 채울 때**
- 같은 지침을 가진 작업자를 **반복해서** 쓸 때
- 보조의 **도구 접근을 제한**하고 싶을 때
- **저렴한 모델(haiku)** 에 일을 보내고 싶을 때

## 이미 들어 있는 서브에이전트
| 이름 | 역할 |
|---|---|
| Explore | 읽기 전용 탐색 |
| Plan | 플랜 모드용 조사 |
| general-purpose | 모든 도구를 쓰는 범용 작업 |
| claude-code-guide | Claude Code 기능 질문 |

## 만들기
말로 요청하는 것이 가장 쉽습니다.
```text
코드 검토 전용 서브에이전트를 만들어 줘. 파일 읽기만 가능하고 수정은 못 하게.
```
또는 `.claude\agents\` 폴더에 마크다운 파일을 직접 만듭니다.

```markdown
---
name: code-reviewer
description: 코드 품질과 보안을 검토합니다. 변경 후 검토가 필요할 때 사용
tools: Read, Glob, Grep
model: sonnet
---

당신은 코드 리뷰어입니다. 변경된 파일을 읽고
문제점과 개선안을 구체적으로 알려 주세요. 파일은 수정하지 않습니다.
```

| 필드 | 설명 |
|---|---|
| `name` · `description` | **필수.** description이 "언제 부를지"의 기준 |
| `tools` | 허용할 도구 (생략하면 상속) |
| `model` | sonnet · opus · haiku · fable · inherit 등 |

## 저장 위치
| 위치 | 범위 |
|---|---|
| `.claude\agents\` | 이 프로젝트 |
| `%USERPROFILE%\.claude\agents\` | 내 모든 프로젝트 |

> `/agents`의 동작은 버전에 따라 다릅니다. 최근 버전은 직접 만들도록 안내하고, 이전 버전은 대화형 마법사를 엽니다.

## 확인 체크
- [ ] 서브에이전트를 하나 만들었다
- [ ] "로그를 분석해 줘"를 맡기고 요약만 돌아오는 것을 확인했다

## 자주 하는 실수
- **description이 모호** → Claude가 언제 불러야 할지 모릅니다
- 서브에이전트도 **사용량에 포함**됩니다
- 서브에이전트가 고친 파일은 `/rewind`로 대부분 복원되지 않습니다
