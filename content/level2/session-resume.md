# 대화 이어하기 (/rename · /resume)

> 어제 하던 일을 **오늘 그대로 이어서** 하는 방법입니다. 대화에 이름을 붙여 두고(`/rename`), 나중에 꺼내 옵니다(`/resume`).

## 먼저: 세션이란
Claude Code에서 시작한 **대화 하나가 세션 하나**입니다. 터미널을 닫아도 대화 기록은 내 컴퓨터에 남아서 다시 불러올 수 있습니다.

| 명령 | 하는 일 |
|---|---|
| `/clear` | 지금 대화를 **비우고 새로 시작** (이전 대화는 `/resume` 목록에 남음) |
| `/compact` | 같은 대화를 **요약해서 공간 확보** |
| `/resume` | **이전 대화로 갈아타기** |

## `/rename` — 이름 붙이기
```text
/rename 로그인 버그 수정
```
- 지금 대화의 이름이 바뀌고, **입력창 아래에 이름이 표시됩니다**
- 이름 없이 `/rename`만 입력하면 대화 내용을 보고 **Claude가 이름을 지어 줍니다**
- 이름은 최대 200자입니다

시작할 때부터 이름을 붙일 수도 있습니다.
```powershell
claude -n "로그인-버그"
```

## `/resume` — 이어서 하기
```text
/resume                    # 이전 대화 목록에서 고르기
/resume 로그인 버그 수정      # 이름으로 바로 열기
```
- 불러오면 **그때의 대화가 그대로 복원**되어, Claude가 맥락을 알고 이어서 일합니다
- 이름을 붙여 두면 목록에서 찾기 쉽습니다

## 터미널에서 바로 이어 하기
`claude`를 켤 때 옵션을 붙이면 됩니다.

| 명령 | 효과 |
|---|---|
| `claude -c` | **지금 폴더에서 가장 최근** 대화를 바로 이어 감 |
| `claude -r "이름"` | 이름이나 ID로 지정해서 이어 감 |

## `/status` — 지금 상태 확인
```text
/status
```
**버전, 모델, 계정, 연결 상태**를 보여 줍니다. 이어서 작업하기 전에 "지금 어느 계정으로, 어떤 모델로 쓰고 있나"를 확인할 때 씁니다. 화면이 이상하거나 오류가 날 때 가장 먼저 열어 보는 명령이기도 합니다.

## 이렇게 써 보세요
1. 일을 시작할 때 `/rename 회의록-정리`처럼 이름을 붙입니다
2. 오늘 작업을 마치고 `claude`를 닫습니다
3. 내일 **같은 폴더**에서 `claude -c`로 열거나, `claude`를 켠 뒤 `/resume`으로 고릅니다
4. `/status`로 계정·모델을 확인하고 이어서 요청합니다

## 확인 체크
- [ ] `/rename`으로 대화에 이름을 붙였다
- [ ] `claude`를 닫았다가 다시 열어 `/resume`으로 이어 봤다
- [ ] `/status`를 실행해 버전과 모델을 확인했다

## 자주 하는 실수
- `/clear`를 하면 이전 대화가 **사라진 줄** 압니다 → 목록에 남아 있어 `/resume`으로 다시 열 수 있습니다
- 대화가 너무 길어진 채로 이어 감 → 이어 하기 전에 `/context`로 확인하고 필요하면 `/compact`
- 이름 없이 쓰다가 **어느 대화인지 몰라서** 헤맴 → 시작할 때 `/rename`부터
