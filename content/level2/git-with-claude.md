# Claude와 함께 git 쓰기

> git 명령을 외우지 않아도 됩니다. **말로 시키고, 결과는 직접 확인**하세요.

## 기본 흐름

```text
1. 작업 전   "현재 상태를 커밋해 줘"        ← 안전한 출발점 만들기
2. 작업      "로그인 오류를 고쳐 줘"
3. 확인      "git diff 로 바뀐 내용을 설명해 줘"
4. 저장      "의미 있는 커밋 메시지로 커밋해 줘"
```

## 자주 쓰는 요청
| 하고 싶은 일 | 이렇게 말하기 |
|---|---|
| 상태 보기 | "지금 바뀐 파일을 요약해 줘" |
| 커밋 | "변경 내용을 보고 한국어 커밋 메시지로 커밋해 줘" |
| 되돌리기 | "마지막 커밋 이후의 수정을 모두 취소해 줘" (⚠ 내용 확인 후 승인) |
| PR 만들기 | "변경 내용을 요약하고 PR을 만들어 줘" |

## PR 만들기 (GitHub)
공식 예시처럼 변경을 요약한 뒤 **"create a pr"** 처럼 요청하면 Claude가 `gh pr create`로 PR을 만듭니다.
- 이 세션은 PR과 연결되어 나중에 `claude --from-pr 1234`로 다시 찾을 수 있습니다
- GitHub CLI(`gh`)가 설치되어 있어야 편합니다

## 안전 수칙
1. **큰 작업 전에는 커밋** — rewind는 빠른 취소, 커밋이 진짜 안전망
2. 커밋·푸시 명령은 **승인 화면에서 내용을 읽고** 허용
3. **`git push`는 규칙으로 확인** 받도록 설정하면 안전합니다
   ```json
   { "permissions": { "ask": ["Bash(git push *)"] } }
   ```
4. 비밀 파일(`.env`)은 `.gitignore`에 넣기

- 커밋 내용을 **읽지 않고 push**
- 한 커밋에 **여러 주제 섞기** → "주제별로 나눠서 커밋해 줘"
