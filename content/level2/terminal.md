# 터미널이란

> 마우스 대신 **글자로 명령**하는 창입니다.
>
> Claude Code는 터미널에서 실행되므로, **기본 명령어 몇 개**는 알아 두어야 합니다.

![터미널 화면 구조](assets/img/terminal-anatomy.svg)

## 열기 (Windows)
1. 시작 메뉴 → **PowerShell** 검색 → 실행

## 실제 실행 화면
![pwd와 dir 실행 결과](assets/img/shots/terminal-basic.png)

## 딱 4개만
```powershell
pwd         # 지금 내가 어느 폴더에 있는지
dir         # 지금 폴더에 어떤 파일과 폴더가 있는지
cd 폴더명   # 그 폴더로 이동
cd ..       # 한 단계 위 폴더로 이동
```

> **팁: Tab 키로 자동완성** — `cd 폴`까지만 치고 **Tab**을 누르면 폴더 이름이 자동으로 채워집니다. 같은 글자로 시작하는 폴더가 여러 개면 Tab을 누를 때마다 후보가 차례로 바뀝니다. 긴 이름을 직접 다 칠 필요가 없고, 오타도 줄어듭니다.

## 확인 체크
- [ ] `pwd`로 현재 폴더가 보인다
- [ ] `cd`로 다른 폴더에 다녀왔다

## 자주 하는 실수
- 엉뚱한 폴더에서 Claude Code 실행 → **실행 전 `pwd` 확인**
