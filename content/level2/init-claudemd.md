# /init 과 CLAUDE.md

> Claude는 대화가 끝나면 잊어버립니다. **매번 알려줄 내용을 CLAUDE.md에 적어 두면** 새 대화마다 자동으로 읽습니다.

> `.md`가 낯설다면 먼저 [마크다운(.md) 파일이란](#/level2/markdown-basics)을 보세요.

![CLAUDE.md 위치](assets/img/claudemd-layers.svg)

## 가장 쉬운 시작: /init
프로젝트 폴더에서 `claude` 실행 후
```text
/init
```
폴더를 분석해 **빌드·테스트 방법, 프로젝트 규칙**이 담긴 `CLAUDE.md`를 만들어 줍니다. 이미 있으면 덮어쓰지 않고 개선안을 제안합니다.

## 어디에 둘까
| 위치 | 용도 |
|---|---|
| `./CLAUDE.md` | **프로젝트 공통** (팀과 공유, 가장 많이 사용) |
| `%USERPROFILE%\.claude\CLAUDE.md` | 내 모든 프로젝트에 적용할 개인 규칙 |
| `./CLAUDE.local.md` | 나만 쓰는 메모 (git에 올리지 않기) |

## 좋은 CLAUDE.md 예시
```markdown
# 프로젝트 안내
- 이 폴더는 주간 회의록 정리 도구입니다
- 결과는 항상 마크다운 표로 작성합니다
- 날짜 형식은 2026-11-14 처럼 씁니다

# 규칙
- 원본 파일(.txt)은 절대 수정하지 않습니다
- 답변은 한국어로, 존댓말로 합니다
```

## 작성 팁 (공식 권장)
- **200줄 이하**로 짧게 — 길면 지시를 덜 따릅니다
- "깔끔하게" 대신 **검증 가능한 문장** ("2칸 들여쓰기")
- **모순되는 지시**가 없도록 가끔 정리
- 다른 파일을 불러오려면 `@경로` (import)
- 사람용 메모는 `<!-- 주석 -->` — 컨텍스트에 들어가지 않습니다

## 편집하는 법
- `/memory` — 파일 목록을 열고 편집
- 말로 요청: "이 규칙을 CLAUDE.md에 추가해 줘"
- "기억해 줘"라고만 하면 CLAUDE.md가 아니라 **자동 메모리**에 저장됩니다

## 확인 체크
- [ ] `/init`으로 CLAUDE.md를 만들었다
- [ ] 규칙 3줄을 직접 추가했다
- [ ] 새 대화(`/clear`)에서도 규칙이 지켜지는지 확인했다

## 자주 하는 실수
- **비밀번호·API 키**를 CLAUDE.md에 적기 → 파일이 공유되면 유출됩니다
- 너무 길게 → 핵심만 남기고 나머지는 스킬로 분리
