# 공식 문서 보는 법

> Claude Code는 **자주 업데이트**됩니다. 막히면 가장 믿을 수 있는 곳은 공식 문서입니다.

| 알고 싶은 것 | 주소 |
|---|---|
| 문서 홈 | [code.claude.com/docs](https://code.claude.com/docs) |
| 한국어 문서 | 주소의 `/docs/ko/` 경로 |
| 빠른 시작 | [quickstart](https://code.claude.com/docs/ko/quickstart) |
| 모든 명령 | [commands](https://code.claude.com/docs/en/commands) |
| 설정 항목 | [settings](https://code.claude.com/docs/ko/settings) |
| 변경 이력 | [changelog](https://code.claude.com/docs/en/changelog) |
| 문서 전체 목차 | [llms.txt](https://code.claude.com/docs/llms.txt) |

## 읽는 요령
1. **내 버전부터 확인**: `claude -v`
2. 한국어 문서에 없으면 **영문 문서**를 보세요 (영문이 원본이고 모든 페이지가 있습니다)
3. **오류 메시지는 영문 그대로** 검색하세요 (번역하면 못 찾습니다)
4. 문서 설명이 현재 버전과 다르면 [changelog](https://code.claude.com/docs/en/changelog)를 확인

## Claude에게 물어보기
```text
Claude Code에서 플랜 모드는 어떻게 켜? 공식 문서 기준으로 알려 줘
```
기능 질문은 Claude Code 자신에게 물어도 됩니다. 중요한 설정은 **문서 링크로 다시 확인**하세요.

## 확인 체크
- [ ] 문서 홈과 changelog를 열어 봤다
- [ ] 내 Claude Code 버전을 확인했다

- 블로그·영상의 **옛날 설명**을 그대로 따라 하기 → 날짜와 버전을 확인
