# PowerShell 기본 명령

> 폴더 만들기, 파일 쓰기, 읽기, 목록 보기. **이 4개면 Claude Code 작업 폴더를 다룰 수 있습니다.**

![실제 실행 화면](assets/img/shots/powershell-basics.png)

## 핵심 명령

| 하고 싶은 일 | 명령 |
|---|---|
| 지금 위치 확인 | `pwd` |
| 폴더 목록 보기 | `dir` |
| 폴더 만들기 | `mkdir 폴더명` |
| 폴더 이동 | `cd 폴더명` |
| 한 단계 위로 | `cd ..` |
| 파일 내용 보기 | `Get-Content 파일명` |
| 파일 만들기·쓰기 | `Set-Content 파일명 "내용"` |
| 화면 지우기 | `cls` |

## 꿀팁
- **Tab 키**: 폴더·파일 이름을 자동 완성합니다
- **↑ 키**: 방금 친 명령을 다시 불러옵니다
- 경로에 공백이 있으면 `"따옴표"`로 감싸기

## 확인 체크
- [ ] 폴더를 만들고 그 안으로 이동했다
- [ ] 파일을 만들고 내용을 읽어 봤다

- 한글 경로·공백 경로에서 오류 → 따옴표로 감싸기
