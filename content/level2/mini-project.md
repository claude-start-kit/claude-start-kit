# 실전: 회의록 정리기 만들기

> 배운 것을 모두 써 봅니다. **회의 메모 → 결정사항·담당자·마감일 표**를 만드는 일입니다. 누구나 자주 하는 업무라 따라 하기 좋은 주제입니다.

## 완성 모습
![회의록 정리 결과](assets/img/shots/mini-meeting.png)

## 단계별 따라하기

### 1단계 — 작업 폴더 준비 (터미널)
```powershell
cd ~
mkdir meeting-demo
cd meeting-demo
Set-Content meeting.txt -Encoding UTF8 "11/14 주간회의. 김대리가 12/1까지 견적서 초안을 보내기로 함. 신규 캠페인 예산은 보류. 박과장이 다음 주 수요일까지 경쟁사 조사 정리. 11/21 재논의."
git init -b main
claude
```

### 2단계 — 규칙 만들기 (`/init` 또는 직접)
```text
이 폴더 규칙을 CLAUDE.md에 적어 줘:
- 원본 .txt는 수정하지 않는다
- 결과는 마크다운 표(결정사항, 담당자, 마감일)로 쓴다
- 정보가 없으면 '미정'으로 쓴다
```

### 3단계 — 먼저 계획 (플랜 모드)
`Shift+Tab`으로 plan mode 후
```text
meeting.txt를 읽고 위 규칙대로 summary.md를 만드는 방법을 계획해 줘
```

### 4단계 — 실행과 확인
계획을 읽고 승인한 뒤
```text
계획대로 summary.md를 만들어 줘. 끝나면 원문과 대조해서 틀린 곳이 없는지 확인해 줘
```

### 5단계 — 저장
```text
변경 내용을 요약하고 의미 있는 커밋 메시지로 커밋해 줘
```

## 결과를 꼭 검증하세요
위 화면에서 Claude는 **"다음 주 수요일"을 오늘 날짜 기준으로 11/25로 계산**했다고 스스로 밝혔습니다. 회의일(11/14) 기준으로 계산했다면 날짜가 달라질 수 있습니다. 원문에 없는 날짜를 **추정**한 것이므로, 표를 그대로 쓰지 말고 사람이 확인해야 합니다.

## 응용 아이디어
| 업무 | 응용 |
|---|---|
| 회의와 업무 기록 | 여러 회의록을 모아 **이전 결정과 비교** |
| 문서와 발표 자료 | 보고서를 임원용 **5줄 요약**으로 |
| 데이터 분석 | 엑셀 CSV의 **이상값** 찾기 |
| 업무 자동화 | 매주 같은 보고서 **초안 자동 작성** |

> 다음 레슨 **「내 업무 자동화 하나 만들기」**에서는 예제 대신 **내 업무**로 같은 과정을 해 봅니다.

## 확인 체크
- [ ] `summary.md`가 만들어졌다
- [ ] 원문과 **직접 대조**해 틀린 곳을 찾았다
- [ ] 변경을 git에 커밋했다

## 자주 하는 실수
- 회의록에 **고객 정보·개인정보**가 있는데 그대로 사용 → 회사 정책을 먼저 확인
- 결과를 **검증 없이** 공유
