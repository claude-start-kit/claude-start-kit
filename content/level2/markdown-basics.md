# 마크다운(.md) 파일이란

> `.md`는 **기호 몇 개로 제목·목록·표를 표시하는 글자 파일**입니다. 메모장으로도 열립니다. Claude Code의 규칙, 요약, 설정이 대부분 이 형식이라 꼭 알아 두세요.

## 어디에 나오나
| 파일 | 용도 |
|---|---|
| `CLAUDE.md` | Claude에게 알려 줄 **규칙** ([/init 과 CLAUDE.md](#/level2/init-claudemd)) |
| `summary.md` | Claude가 만들어 주는 **결과물** (회의록 요약 등) |
| `.claude\agents\*.md` | **서브에이전트** 설정 |

## 자주 쓰는 기호 5개
| 쓰는 법 | 보이는 모양 |
|---|---|
| `# 제목` | 큰 제목 (`##`, `###`은 더 작은 제목) |
| `- 항목` | 글머리 목록 |
| `**굵게**` | **굵게** |
| `` `코드` `` | `코드` 모양 |
| `\| 칸 \| 칸 \|` | 표 |

예를 들어 아래처럼 쓰면
```markdown
# 오늘 할 일
- **회의록 정리**
- 견적서 확인
```
이렇게 보입니다.

> # 오늘 할 일
> - **회의록 정리**
> - 견적서 확인

## 왜 Claude는 .md를 쓰나
- 사람이 읽기 쉽습니다. 기호가 없어도 글이 그대로 읽힙니다
- 기호가 단순해서 **AI가 구조(제목, 목록, 표)를 정확히 읽고 씁니다**
- 그래서 규칙도 결과물도 `.md`로 주고받는 것이 가장 편합니다

## 직접 해 보기
1. VS Code에서 [프로젝트 폴더](#/level2/project-folder)를 열고 터미널에서 `claude`를 실행합니다
2. 이렇게 요청합니다

   ```text
   notes.md 파일을 만들고, 오늘 할 일 3개를 제목과 목록으로 적어 줘
   ```

3. 왼쪽 파일 목록에서 `notes.md`를 열어 기호가 어떻게 쓰였는지 봅니다
4. `Ctrl+Shift+V`를 누르면 **보이는 모양(미리보기)** 으로 바뀝니다. 다시 누르면 원래 글로 돌아옵니다

> 나란히 보고 싶다면 `Ctrl+K` 를 누른 뒤 `V`를 누르세요. 글을 고치는 대로 미리보기가 바뀝니다.

## 확인 체크
- [ ] `.md`가 기호로 모양을 표시하는 글자 파일이라는 것을 안다
- [ ] `Ctrl+Shift+V`로 `.md` 미리보기를 열어 봤다

## 자주 하는 실수
- `.md`를 **워드 같은 문서 파일**로 착각 → 그냥 글자 파일입니다. 메모장으로 열려도 정상입니다
- 기호를 **외우려고** 함 → 모양만 알면 됩니다. 필요하면 Claude에게 "마크다운으로 써 줘"라고 하세요
